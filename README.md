# IULinux website

The official IULinux 0.1 Alpha 1 website and technical Handbook. This is a lightweight static site intended for Cloudflare Pages.

The site records the current release artifact and its known limitations with the public ISO and checksum endpoints recorded in the release section. Authentic IULinux branding and desktop preview assets are stored in `assets/`; the technical content in `handbook.html` was written from the local read-only IULinux reference repository.

The public ISO and matching SHA-256 endpoints are recorded in the website release section. Before each publication, confirm the release identity/volume label and run a link/accessibility check in the target hosting environment.
